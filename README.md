# 🍔 Burger Haven - Artisanal Food Website

A modern, high-performance artisanal food & restaurant website with smooth **120fps scroll-driven video background scrubbing**, responsive capsule navigation dock, interactive food menu with filtering, and real-time cart order drawer.

---

## ✨ Features

- **🎬 120fps Background Canvas Scrub Engine**: Smooth frame-by-frame scrubbing synchronized directly to user scroll position.
- **📱 Responsive Floating Capsule Dock**: Sleek modern capsule navigation optimized for desktop, tablet, and mobile displays.
- **🍔 Interactive Artisanal Menu**: Real-time category filtering (Signature Burgers, Sides, Drinks, Desserts).
- **🛒 Dynamic Ordering Drawer**: Live cart drawer with add-to-cart counters, price tallies, and interactive order modal.
- **⚡ Zero External Bundler Required**: Pure vanilla HTML5, CSS3, and modern JavaScript—100% compatible with GitHub Pages.

---

## 🚀 Live Demo & GitHub Pages Hosting

This website is ready for 1-click hosting on **GitHub Pages**:

1. Go to your repository on GitHub (`https://github.com/YOUR_USERNAME/food-website`).
2. Navigate to **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.
5. Within 1–2 minutes, your website will be live at:
   ```
   https://YOUR_USERNAME.github.io/food-website/
   ```

---

## 💻 Local Development

Run locally using Node.js:
```bash
node server.js
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.
